# Twin Deck

두 개의 패널을 나란히 놓고 파일을 옮기고 정리하는 파일 관리자입니다. 마우스 없이 키보드만으로도 거의 모든 일을 할 수 있습니다.

![Twin Deck 메인 화면](docs/screenshots/main.png)

- 왼쪽 폴더에서 오른쪽 폴더로 `F5` 한 번에 복사하고 `F6`으로 옮깁니다.
- 파일을 열기 전에 `→` 키로 내용부터 봅니다. 코드, 문서, 이미지, PDF, 압축 파일, 만화, 동영상을 지원합니다.
- 폴더별 용량을 크기에 비례한 타일로 한눈에 보고, 이름이나 내용으로 파일을 찾고, 탭으로 여러 폴더를 오갑니다.
- 색 테마 112가지와 글꼴·단축키 설정을 바꿀 수 있고, 화면 언어는 한국어와 English 중에서 고릅니다.

macOS(Apple Silicon)와 Windows(x64)용을 [릴리스 페이지](https://github.com/gyuha/twin-deck/releases)에서 받을 수 있습니다.

## 설치

### macOS: Homebrew (권장)

Apple Silicon Mac에서 [자체 Homebrew tap](https://github.com/gyuha/homebrew-tap)으로 설치합니다.

```sh
brew install --cask gyuha/tap/twin-deck
```

- **앱이 바로 열립니다.** Twin Deck은 Apple 개발자 인증서로 서명하거나 공증하지 않은 앱이라 보통은 첫 실행에서 macOS가 막습니다(Gatekeeper). Homebrew로 설치하면 설치 직후 이 차단 표시를 지워 경고 없이 열립니다. 이 검사를 우회하는 것이므로 출처를 신뢰하는 경우에만 설치하세요.
- **Apple Silicon만 지원합니다.** Intel Mac에서는 설치가 거부됩니다.
- **업데이트는 앱 안에서 합니다.** `brew upgrade`는 이 앱을 건너뜁니다. 아래 "업데이트"를 보세요.

### macOS: 직접 내려받기

Homebrew를 쓰지 않으면 직접 설치합니다. 서명하지 않은 앱이라 처음 열 때 "확인되지 않은 개발자" 경고로 막히는데, 아래 순서대로 한 번만 허용하면 이후에는 일반 앱처럼 열립니다.

1. [릴리스 페이지](https://github.com/gyuha/twin-deck/releases)에서 `twin-deck-<버전>-macos-arm64.zip`을 내려받습니다.
2. 압축을 풀면 `Twin Deck.app`이 나옵니다. 이것을 `/Applications` 폴더로 옮깁니다.
3. 터미널에서 차단 표시(quarantine)를 지웁니다. 가장 확실한 방법입니다.

   ```sh
   xattr -dr com.apple.quarantine "/Applications/Twin Deck.app"
   ```

4. `Twin Deck.app`을 엽니다.

터미널을 쓰고 싶지 않으면 3번 대신 이렇게 합니다.

- 앱을 한 번 열어 봅니다(경고가 뜨고 열리지 않습니다).
- **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽의 "Twin Deck이(가) 차단되었습니다" 옆 **그래도 열기**를 누르고 암호나 Touch ID로 확인합니다.
- macOS 14 이하에서는 앱을 우클릭(Control+클릭)한 뒤 **열기**를 눌러도 됩니다. macOS 15 이상에서는 이 방법이 막혀서 위의 시스템 설정 방법이나 `xattr`를 써야 합니다.

```
zip 내려받기 → 압축 풀기 → /Applications로 이동 → xattr 로 차단 표시 지우기 → 실행
                                                    ↓ 터미널을 쓰지 않을 때
                                    앱 실행(차단됨) → 시스템 설정 > 개인정보 보호 및 보안 > 그래도 열기 → 실행
```

막는 이유는 앱에 문제가 있어서가 아니라 서명과 공증이 없어서입니다. 출처를 신뢰할 수 있을 때만 허용하세요.

### Windows

[릴리스 페이지](https://github.com/gyuha/twin-deck/releases)에서 `twin-deck-<버전>-windows-x64-setup.exe`를 내려받아 실행합니다. 서명하지 않은 설치 파일이라 Windows가 실행 전에 경고를 보일 수 있습니다. 출처를 확인하고 진행하세요.

### 그 밖의 환경

Intel Mac과 Linux용 설치 파일은 없습니다. 아래 "소스에서 빌드"를 따라 직접 빌드해서 쓸 수 있습니다.

### 업데이트

설정 화면(`Mod+,`, macOS는 메뉴바의 **설정…**, 모든 OS는 아래쪽 상태 표시줄의 **설정** 버튼) 위쪽의 **업데이트 확인** 버튼을 누르거나, 액션 패널(`Mod+Shift+P`)에서 "업데이트"를 실행합니다. 새 버전이 있으면 변경 사항을 보여 주고, 설치한 뒤 앱을 다시 시작합니다. 앱이 스스로 확인하지는 않으니 가끔 눌러 보세요.

`Mod`는 macOS에서 `Cmd`, Windows에서 `Ctrl`입니다.

## 처음 시작하기

앱을 열면 패널이 둘 보입니다. 테두리가 강조된 쪽이 지금 쓰고 있는 패널이고, 복사와 이동은 이 패널에서 반대쪽 패널의 폴더로 갑니다. 먼저 이 키들만 익히면 됩니다.

| 하고 싶은 일 | 키 |
|---|---|
| 패널 바꾸기 | `Tab` |
| 파일 위아래로 고르기 | `↑` `↓` |
| 폴더 안으로 들어가기 / 상위 폴더로 | `Return` / `Backspace` |
| 여러 개 고르기 | `Space` |
| 반대쪽 패널로 복사 / 이동 | `F5` / `F6` |
| 열지 않고 내용 보기 | `→` |
| 모든 기능을 이름으로 찾아 실행 | `Mod+Shift+P` |

복사하는 흐름은 이렇습니다. 복사할 파일에 커서를 두거나 `Space`로 여러 개 고른 뒤 `F5`를 누르면 "대상 폴더"를 확인하는 창이 뜹니다. 기본값은 반대쪽 패널이 열고 있는 폴더이고, `Return`을 누르면 복사가 시작됩니다. 같은 이름의 파일이 이미 있으면 어떻게 할지 묻습니다.

```
파일 고르기(↑↓, Space) → F5 → 대상 폴더 확인 (기본: 반대쪽 패널의 폴더) → Return → 복사 (진행 창)
                                                                    ↓ 같은 이름이 이미 있으면
                                                    덮어쓰기 / 건너뛰기 / 이름을 바꿔 복사 중에서 선택
```

모든 단축키는 `F1`(또는 상태 표시줄의 **단축키** 버튼, macOS는 Help 메뉴의 **단축키 목록**)을 누르면 목록으로 볼 수 있고, 설정 폴더의 `keybindings.toml`로 바꿀 수 있습니다.

## 할 수 있는 일

### 파일 옮기고 정리하기

- **복사·이동·삭제**: `F5` 복사, `F6` 이동, `F7` 새 폴더, `Shift+F7` 새 파일, `F8` 휴지통, `Shift+F8` 영구 삭제입니다.
- **오래 걸리는 작업**: 진행 창에서 진행률을 봅니다. `Return`을 누르면 백그라운드로 보내고 계속 다른 일을 할 수 있고, `Esc`를 누르면 중단합니다. 폴더를 복사하다가 일부 파일이 실패해도 나머지는 계속 복사하고, 실패한 항목은 목록으로 보여 줍니다.
- **이름이 겹칠 때**: 덮어쓰기, 건너뛰기, 이름을 바꿔 복사 중에서 고릅니다. "남은 항목에도 같은 선택 적용"을 켜면 다시 묻지 않습니다.
- **이름 바꾸기**: `F2`로 하나를 바꿉니다. 둘 이상 고른 뒤 `F2`(또는 `Mod+Shift+R`)를 누르면 한꺼번에 바꾸는 창이 열립니다.
- **압축 파일**: zip 계열 압축 파일을 폴더처럼 열어 볼 수 있고, 압축하고 푸는 작업도 복사처럼 백그라운드에서 진행합니다.
- **끌어서 놓기**: 파일을 끌어 다른 패널이나 폴더에 놓으면 복사하고, `Ctrl`을 누른 채 놓으면 이동합니다. 끄는 동안 커서 옆에 복사(`+`)와 이동(`−`) 표시가 나옵니다.

  ![드래그로 복사](docs/screenshots/drag-copy.png)

- **다른 앱과 주고받기**: 파일을 창 밖으로 끌어 Finder나 탐색기에 놓으면 복사됩니다(macOS, Windows). `Mod+C`, `Mod+X`, `Mod+V`도 운영체제의 파일 클립보드와 이어져 있어서, Finder나 탐색기와 파일을 주고받을 수 있습니다. 잘라낸 파일은 붙여 넣을 때 이동합니다.

### 열기 전에 미리보기

파일에 커서를 두고 `→`(또는 `Mod+Y`)를 누르면 파일을 열지 않고 내용을 바로 봅니다. `Esc`나 `Space`를 누르면 닫히고, 열린 채로 `↑` `↓`를 누르면 이전·다음 파일로 넘어갑니다.

![코드 미리보기](docs/screenshots/preview-code.png)

| 종류 | 보이는 것 |
|---|---|
| 텍스트, 코드, Markdown, JSON | 내용 (코드는 구문 색상) |
| 이미지, PDF | 그림과 PDF 페이지 |
| 만화 압축 파일(`.cbz`) | 안의 첫 이미지 |
| 그 밖의 압축 파일 | 안의 파일 목록 |
| 폴더 | 하위 항목을 가지 모양 목록으로 |
| 사운드, 비디오 | 재생 화면. 재생 버튼을 눌러야 재생 |
| 3D 모델(GLB, OBJ, STL 등) | 3D로 그린 화면 |
| epub | 표지·제목·저자와 목차, 챕터 본문. 챕터는 `Ctrl+Tab`/`Ctrl+Shift+Tab`이나 목차 상자로 넘깁니다(디스크 위 파일만, DRM이 걸린 파일은 제외) |

![cbz 미리보기](docs/screenshots/preview-cbz.png)

- 폴더에서 `Shift+→`를 누르면 폴더 안으로 들어가지 않고 폴더를 미리봅니다.
- 미리보기 창은 제목 줄을 끌어 옮기고 가장자리를 끌어 크기를 바꿀 수 있고, 위치와 크기를 기억합니다.
- 사운드와 비디오를 열자마자 재생하려면 설정의 **미리보기** 탭에서 켭니다.
- **Office 문서(docx, xlsx, pptx)**: macOS는 Quick Look으로 실제 문서 모습 그대로 보여 줍니다(설정과 관계없음). Windows는 **docx만** 설치된 Office의 미리보기 처리기(탐색기 미리보기 창이 쓰는 것)로 실제 모습을 보여 주고(인터넷에서 받은 파일은 "차단 해제하고 보기"가 필요합니다), xlsx·pptx는 아래의 데이터 미리보기입니다. docx도 처리기가 없으면(Office가 없는 Windows 등) 데이터 미리보기로 돌아가고, Linux는 처음부터 데이터 미리보기입니다. 데이터 미리보기는 기본으로 꺼져 있습니다. 설정의 **미리보기** 탭에서 "Office 문서 미리보기"를 켜면 보입니다. 문서 화면이 아니라 안의 데이터만 보여 주기 때문에 서식, 배치, 그림은 나오지 않습니다.

### 파일 찾기

`Mod+F`를 누르면 찾기 창이 열립니다. 이름의 일부나 마스크, 정규식, 파일 안의 글자, 찾을 깊이, 제외할 이름을 정해 찾을 수 있습니다. 결과는 새 탭으로 열립니다.

![파일 찾기 결과](docs/screenshots/find.png)

### 폴더 용량을 한눈에

용량을 많이 차지하는 폴더를 찾을 때는 폴더에서 `Alt+T`를 누릅니다. 하위 폴더와 파일이 크기에 비례한 타일로 그려져서 어디가 큰지 바로 보입니다. 전체의 0.5%보다 작은 항목은 "기타 N개" 타일로 묶입니다.

![디스크 사용량 treemap](docs/screenshots/treemap.png)

| 하고 싶은 일 | 키 |
|---|---|
| 타일 사이 옮기기 | `←` `→` `↑` `↓` (화면에서 그 방향의 이웃 타일로) |
| 그 폴더를 반대쪽 패널에서 열기 | `Return` 또는 타일 클릭 |
| 폴더 안으로 내려가기 | `Shift+→`, `Mod+Return` 또는 더블클릭 |
| 한 단계 위로 | `Backspace` |
| 목록 보기와 타일 보기 바꾸기 | `Alt+T` |
| 나가기 | `q` |

### 탭과 패널

- **탭**: 패널마다 탭을 여럿 둘 수 있습니다. `Mod+T`로 새 탭, `Mod+W`로 닫기이고, 탭을 마우스 가운데 버튼으로 눌러도 닫힙니다.
- **탭 끌기**: 탭을 끌어 같은 패널 안에서 순서를 바꾸고, 반대쪽 패널의 탭 줄에 놓으면 그쪽으로 보냅니다. 원래 패널에 탭이 하나뿐이면 옮기지 않고 복사합니다.
- **패널 맞바꾸기**: `Mod+U`를 누르면 왼쪽과 오른쪽 패널의 탭, 폴더, 커서, 선택을 통째로 맞바꿉니다.
- **패널 폭**: 가운데 경계를 끌어 조절합니다.
- **빨리 가기**: `Alt+2`는 즐겨찾기 메뉴, `Alt+3`은 최근 위치 메뉴이고 둘 다 입력해서 걸러 볼 수 있습니다. 즐겨찾기 메뉴에서 `Ctrl+=`로 현재 폴더를 추가합니다. 자주 가는 폴더는 설정의 **폴더 단축키** 탭에서 `Ctrl+0`~`9`에 지정할 수 있습니다.
- **드라이브 바**: 패널 위에서 볼륨을 고르고 꺼낼 수 있습니다. 남은 용량은 경로 표시줄 오른쪽 끝에 보입니다.
- **내장 터미널**: `Alt+Mod+T`를 누르면 지금 폴더에서 시작하는 터미널(`xterm.js`) 탭이 반대쪽 패널의 탭 줄에 생깁니다. 누를 때마다 새 탭이고, 탭을 옮겨도 셸과 화면은 그대로 살아 있습니다. 글꼴은 설정의 **터미널 글꼴**(`behavior.terminal_font`, 미리보기 글꼴과 따로)이고 바꾸면 열린 터미널에 바로 적용됩니다. 탭을 닫거나(`Mod+W`) 셸이 끝나면(`exit`, `Ctrl+D`) 세션이 끝납니다. 터미널 탭에서는 키가 셸로 가고, 새 터미널과 탭 이동·닫기 키만 앱이 받습니다. 검색 결과나 압축 파일 안에서는 열지 않습니다. 파일 우클릭 메뉴의 **터미널 열기**로도 엽니다.

### 취향에 맞게 바꾸기

`Mod+,`를 누르면 설정 화면이 열립니다. 항목 이름 옆의 **ⓘ**에 마우스를 올리면 설명이 말풍선으로 보입니다.

![설정 화면](docs/screenshots/settings.png)

- **언어**: **모양** 탭의 "언어"에서 한국어와 English 중에서 고릅니다. 바꾸면 화면과 macOS 메뉴바가 바로 바뀌고, 기본은 한국어입니다. 문서(README, `docs/`)와 변경 사항은 한국어이고 README는 [영어판](README.en.md)이 있습니다.
- **색 테마**: **모양** 탭의 "테마"에서 112가지 중에서 고릅니다. 이름이나 "어두움"/"밝음"으로 검색할 수 있습니다. 기본값은 `system`이고, 컴퓨터가 다크 모드이면 Catppuccin Mocha, 아니면 Catppuccin Latte를 씁니다.

  | 밝은 테마 (Catppuccin Latte) | 다른 어두운 테마 (Dracula) |
  |---|---|
  | ![밝은 테마](docs/screenshots/theme-light.png) | ![Dracula 테마](docs/screenshots/theme-dracula.png) |

- **글꼴과 글자 색**: 화면 글꼴과 미리보기 글꼴을 따로 정하고, 앱 기본 글자 색을 바꿉니다.
- **목록 모양**: 아이콘 크기, 줄무늬 행, 폴더 이름 꾸밈, 탭 모양, 활성 패널 테두리 강조 등을 고릅니다.
- **F키**: `F1`~`F12`(조합키 포함)마다 내장 동작이나 외부 프로그램 실행을 지정하고, 아래쪽 막대에 보일지 정합니다.
- **키 바꾸기**: 설정 폴더의 `keybindings.toml`에서 단축키를 바꿉니다.

## 자주 쓰는 단축키

`Mod`는 macOS에서 `Cmd`, Windows에서 `Ctrl`입니다. 전체 목록은 `F1` 도움말이나 `Mod+Shift+P`(액션 패널)에서 볼 수 있습니다.

## 소스에서 빌드

설치 파일이 없는 환경(Intel Mac, Linux)이거나 직접 고쳐서 쓰고 싶을 때 필요합니다.

필요한 것:

- [Rust](https://rustup.rs/) (저장소의 `rust-toolchain.toml`이 stable을 지정합니다)
- [Bun](https://bun.sh/) 1.3 이상, Node 20 이상(`.nvmrc`)
- [Tauri 2 사전 요구 사항](https://v2.tauri.app/start/prerequisites/) (macOS는 Xcode Command Line Tools, Windows는 WebView2와 C++ 빌드 도구)
- [go-task](https://taskfile.dev/) (선택. 없으면 `Taskfile.yml`의 명령을 직접 실행)

```sh
task setup      # 의존성 설치와 툴체인 확인
task dev        # 개발 모드 실행
task test       # Rust와 TS 테스트
task check      # fmt, clippy, 타입 검사
task bundle     # 설치용 번들 만들기 (macOS는 .app, Windows는 NSIS 설치 파일)
task install    # 번들을 만들어 이 PC에 설치 (macOS는 /Applications)
```

릴리스를 만들어 올리는 방법은 [deploy.md](deploy.md)에 있습니다.

## 설정 파일

설정과 키맵은 사람이 읽을 수 있는 TOML 파일입니다. 설정 화면(`Mod+,`)에서 대부분을 바꿀 수 있고, 직접 편집해도 됩니다. `config.toml`을 저장하면 실행 중인 앱에 반영됩니다. 설정 화면 위쪽의 **설정 폴더 열기**로 이 폴더를 열 수 있습니다.

- macOS: `~/Library/Application Support/dev.twindeck.app/config.toml`
- 키맵: 같은 폴더의 `keybindings.toml`
