## 배운 점
- 다음에 다르게 할 것:
  - 구문 강조처럼 "보이는 결과"를 고르는 질문은 표 설명만으로는 사용자가 결과를 상상하기 어렵다. 선택지마다 대표 입력(`git status`, `ls | grep x`)의 실제 칠해진 결과를 미리 보여 주고 고르게 하면 UAT에서 되돌아오는 일을 줄일 수 있다(fg-showme 같은 시각 비교 후보).
  - 투명 글자 input 위에 레이어를 겹치는 기법은 글자 폭을 바꾸는 스타일(기울임·굵게·letter-spacing)을 레이어에서 모두 끄고, 값을 프로그램으로 바꾸는 모든 경로(recall, 붙여넣기)에서 스크롤을 다시 맞춰야 한다. 다음에 같은 기법을 쓰면 처음부터 두 가지를 체크리스트로 넣는다.
