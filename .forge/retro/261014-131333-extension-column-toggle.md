# 2026-10-14 — 확장자 컬럼 표시 설정과 헤더 정렬

## 계획과 실제
- 기능은 승인한 기준대로 구현했다. 기본 OFF인 표시 스위치, 파일명 유지, 빈 확장자 셀, 헤더 양방향 정렬을 연결했다.
- 별도 불리언 대신 기존 `view.table.columns`를 사용했다. 다른 컬럼의 순서·너비·정렬 표시를 보존하며 저장·재로딩·해제·기본값 복원을 검증했다.
- 관련 UI 테스트는 37개에서 40개로 늘었다. 전체 JavaScript 테스트 1,375개와 모든 패키지 타입 검사가 통과했다. 실제 WKWebView 수동 검증은 하지 않았다.
- 전체 검사에서 기존 테스트 문맥의 필수 필드 누락, WASM 설치 경로 가정, jsdom/Node의 Blob·AbortSignal 구현 차이를 발견해 테스트 코드만 보완했다. 자동 수정 3회를 사용했다.

## 학습
- 다음에는 완료 조건에 포함한 전체 테스트·타입 검사를 초기에 실행해 기존 실패와 새 변경의 영향을 구분한다. 일부 관련 테스트만 통과한 것을 전체 기준값으로 간주하지 않는다.
- 표시 스위치를 추가할 때 기존 설정 목록을 기준으로 파생할 수 있는지 먼저 확인한다. 이번에는 별도 상태를 추가하지 않아 파일 설정과 UI 설정이 충돌하지 않는다.
- jsdom과 Node API가 섞인 테스트는 객체 종류의 호환성을 확인한다. 테스트 API를 제품 결함으로 오인하지 않고 실제 내용 검증·취소 동작은 유지한다.
- 작은 기존 테스트 문제를 기능 작업에 포함할지 별도 작업으로 분리할지는 향후 사용자 선호를 반영할 사항이며, 이번 기록을 일반적인 범위 확대 권한으로 해석하지 않는다.
