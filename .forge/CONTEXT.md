# twin-deck

Marta에서 영감을 받은 이중 패널 크로스 플랫폼 파일 관리자. 이 문서는 프로젝트 고유 용어만 정의한다.

## 파일 아이콘

**아이콘 테마**:
파일 형식과 폴더 이름에 아이콘을 대응시키는 외부 에셋 묶음. 현재는 Material Icon Theme(MIT) 5.38.1을 저장소에 복사해 고정해 쓴다.
_Avoid_: 스킨, 아이콘 팩

**아이콘 해석**:
항목의 이름과 종류(파일/폴더/심볼릭 링크)로 표시할 아이콘 하나를 정하는 규칙. 파일명 전체, 확장자(긴 것부터), 폴더명 순으로 맞추고 모두 실패하면 기본 아이콘을 쓴다.
_Avoid_: 아이콘 매칭, 아이콘 룩업 (Look Up은 검색 기능의 이름이다)

## 복사/이동

**전송**:
복사와 이동을 묶어 부르는 말. 원본을 다른 폴더로 옮기는 작업이라는 점이 같다.
_Avoid_: 파일 작업 (삭제·압축까지 포함하는 더 넓은 말이다)

**전송 확인 창**:
전송을 시작하기 전에 대상 폴더를 보여 주고 고칠 수 있게 하는 모달. 시작하면 전송이 큐에 들어가고, 취소하면 아무것도 하지 않는다.
_Avoid_: 복사 다이얼로그, 확인 팝업

**전송 진행 창**:
실행 중인 전송의 진행을 보여 주는 모달. 처리한 파일 수/전체 파일 수와 지금 처리 중인 파일 경로를 보여 주고, 중단할 수 있다.
_Avoid_: 프로그레스 다이얼로그, 큐 팝업 (큐 팝업은 `=`로 여는 작업 목록이다)

## 모양과 설정

**테마**:
앱 화면의 색을 정하는 이름 붙은 묶음. dark, light, midnight, noir, slate, nord, mocha와 system 중 하나를 고른다. system은 OS의 밝기 설정에 따라 light나 dark를 고른다.
_Avoid_: 스킨, 색 구성표

**내장 기본값**:
앱에 들어 있는 설정 값. 사용자 설정이 이 위에 덮어써진다.

**사용자 설정**:
사용자가 바꾼 값만 담은 설정 파일. 여기에 없는 키는 내장 기본값을 쓴다.
_Avoid_: 설정 파일 (내장 기본값과 구분되지 않는다)

**설정 화면**:
사용자 설정을 항목별 컨트롤로 바꾸는 화면. 바꾸는 즉시 저장하고, "기본값으로"는 그 항목을 사용자 설정에서 지워 내장 기본값으로 되돌린다.
_Avoid_: 환경설정 창, 설정 다이얼로그
