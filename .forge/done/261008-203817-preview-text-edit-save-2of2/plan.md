# 텍스트 미리보기에서 더블클릭으로 편집하고 `Mod+S`로 저장한다 (2/2)

## 목표 / 하지 않을 것
- 목표: 텍스트·마크다운 등 텍스트 계열 미리보기에서 본문을 **더블클릭하면 편집**하고 **`Mod+S`로 저장**한다. (GitHub 이슈 #38 관련 요청: "다시 text editor로 안 열어도 되니까")
  - **편집 가능 조건**(모두 만족해야 한다. 아니면 편집을 시작하지 않고 알림 한 줄에 이유를 보여 준다): ① 디스크 위의 일반 파일(압축 안 경로 제외) ② 전체가 읽힘(`truncated`가 아님, 64KB 이하) ③ UTF-8로 온전히 해석되는 텍스트 ④ 줄바꿈이 LF만이거나 CRLF만이다(섞여 있으면 거부).
  - **편집 방식**: 본문 더블클릭 → 뷰어(마크다운·코드·JSON 포함)를 원문 `textarea`로 바꾸고 포커스한다. 제목 줄에 "편집 중" 표시(변경이 있으면 "●")를 둔다.
  - **키**: 편집 상자가 있는 동안 글자·방향키·`Space`·`Enter`·`Delete`는 상자가 받는다(미리보기 단축키로 가지 않는다. 경로 입력창의 `data-path-edit`와 같은 예외). `Mod+S`는 저장하고 편집 상태를 유지하며 "저장됨"을 잠깐 보인다. `Esc`는 미리보기 닫기가 아니라 **편집 종료**로 먼저 동작한다.
  - **저장 안 한 변경 보호**: 변경이 있을 때 편집이 끝나는 동작(`Esc`, ✕, 바깥 클릭, 이웃 파일 이동, `Mod+Y`, 미리보기 안 삭제 등)이 일어나면 **"저장 / 버리기 / 취소"** 대화상자를 띄운다. 변경이 없으면 확인 없이 편집만 끝난다. 이 3택 대화상자는 기존 대화상자 종류(`confirm`은 2택)에 없어 **새 종류**를 더한다.
  - **줄바꿈 보존**: 파일이 CRLF이면 저장할 때 `\n`을 `\r\n`으로 되돌려 쓰고, LF면 그대로 쓴다. 마지막 줄 끝 줄바꿈 유무도 그대로다.
  - **밖에서 바뀐 파일 보호**: 편집을 시작할 때 `file_info`로 수정 시각·크기를 기억하고, 저장할 때 Rust 쓰기 명령이 현재 값과 비교한다. 달라졌으면 **쓰지 않고** "파일이 밖에서 바뀌었습니다 — 덮어쓰기 / 취소" 대화상자를 보여 준다(덮어쓰기를 고르면 비교 없이 쓴다).
  - **쓰기 방식**: 같은 폴더의 임시 파일에 쓴 뒤 이름을 바꾸는 원자적 쓰기, 기존 파일 권한 유지.
  - 저장 뒤 미리보기 내용과 기억한 수정 시각·크기를 새 값으로 갱신한다(연속 `Mod+S`가 충돌하지 않게).
- 하지 않을 것: 64KB를 넘는 파일 편집 · UTF-8이 아닌 인코딩·섞인 줄바꿈 파일 편집 · 자동 저장 · 되돌리기 이력(브라우저 기본 `Ctrl+Z`는 상자가 처리) · 찾기/바꾸기·구문 강조 편집 · 압축 안 파일 저장 · 편집 중 외부 변경 감지(저장 시점 비교만)
- 의존: 1/2(복사 버튼)와 독립적으로 출시할 수 있다(소프트 순서). 제목 줄 영역을 같이 건드리므로 1/2를 먼저 하면 충돌이 적다.
