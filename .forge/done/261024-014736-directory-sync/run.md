## 기준과 결과
- 비교/복사 기능: 사전 기능 없음 → 임시 폴더 비교·실제 복사·재귀·glob·선택·날짜/내용·방향·빈폴더·취소·종류/링크·NFC/NFD·case 충돌·stale 보호·배타적 교체 통과.
- UI: 사전 기능 없음 → 통합 15개 및 작은 창에서도 고정 하단/표 스크롤, 확인 취소 기본포커스 확인.
- `cargo test --workspace`: 608 통과, 0 실패, 2 무시. 마지막 성능 수정 뒤 관련 엔진10/큐1/서비스1 추가 재통과.
- `bun run test`: 첫 전체 실행 1596 통과, 메뉴 기대값1·새 Rust 오류 번역2·기존 라이선스 창 timeout1 실패. 메뉴/사전 수정 뒤 해당4파일50개 재통과. 최종 전체 재실행 `bun run test --maxWorkers=4 --minWorkers=1`: desktop 190파일/1600개 통과·1개 skip, 패키지136개 통과.
- `bun run typecheck`: 모든 workspace 통과.
- fmt, 변경 crate(td-ops/td-queue/desktop) clippy `-D warnings`, 생성 바인딩 및 라이선스 최신 검사 통과. 기존 all-targets baseline 경고 우회 없음; 지정 crate library/bin gate 사용.

## 구현 판단과 검토
- 로컬 및 OS 마운트 폴더만 지원. 원격/아카이브·겹친 루트·심볼릭 링크·특수 파일·이름/종류 충돌을 거부하거나 제외한다.
- 자동 삭제 없음. 최신/고유 기본 방향 외의 판단 불가 항목은 제외하고 수동 선택한다.
- 내용 비교를 꺼도 변경 보호를 위해 파일 내용을 읽는다. 대용량/네트워크 폴더 비용은 UI 도움말과 문서에 안내했다.
- 배타적 이름 변경을 지원하지 않는 파일시스템에서는 기존 파일 보호를 우선해 실패한다. 일부 항목 성공 뒤 취소/실패는 전체 되돌리기가 아니며 기존 큐로 결과를 확인한다.
- 위험 코드 리뷰에서 발견한 비대칭 API 우회·최종 교체 race·backup 재검증 오류 복원·case 충돌·해시 취소·FIFO를 수정하고 독립 임시 harness로 확인. 남은 critical/high/medium 지적 없음.
- 초기 UI 테스트가 찾은 비교 중 Esc 포커스 유실 수정. 경로 변경 시 선택 조건 해제·늦은 응답 무시·필터와 계획 독립성을 회귀 테스트로 고정했다.
- 기존 캡처 API 오류 후 독립 headless Chromium에서 동일 실제 App+FakeBackend 렌더를 캡처했다. 네이티브 WKWebView 런타임을 직접 조작한 검증은 아니다.
- 시각 시스템 확장 없음. 기존 FindDialog/index.css의 토큰/타입/컨트롤을 상속. detector [] 및 독립 문서화 검토 no changes.
- 다수 파일 계획 생성의 반복 선형 탐색을 인덱스·정렬 집합으로 교체해 O(n²) 증가를 방지했다.

## 향후 작업
구체적으로 미해결된 승인 범위 내 항목 없음. Windows 실행 및 실제 SMB 서버에서의 런타임 동작은 이 macOS 임시 로컬 폴더 검사 범위에 포함되지 않는다.
