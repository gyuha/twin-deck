# 날짜 구간 그룹핑 2/3: 목록에 구간 제목 행과 구간별 정렬 (이슈 #62)

## 목표 / 비목표
- 목표: 설정이 켜져 있으면 단일 컬럼 목록 보기에서 수정일 구간 제목 행을 항목 사이에 보이고, 구간 안은 현재 정렬(폴더 먼저)을 따른다. 1/3이 만든 설정 키와 `lib/dateGroups.ts`를 쓴다.
- 제약: 커서·선택 인덱스는 계속 `tab.entries`의 항목 번호다(제목 행은 항목이 아니다). 목록은 고정 높이(24px) 가상 스크롤이라 행↔항목 대응(행 수·`scrollToIndex`·`aria-rowindex`·`aria-activedescendant`)을 제목 행을 포함해 맞춰야 한다. 제외된 보기(여러 열 보기, 가상 탭)와 설정이 꺼진 경우에는 항목 순서가 평소 정렬 그대로여야 한다(그룹 순서를 정렬 단계에 적용한다면 보기 전환·설정 변경 때 다시 정렬한다).
- 비목표: 접기/펼치기, 제목 클릭 동작, 다른 속성 그룹핑, 새 단축키·액션, 문서(3/3).

- 정의 완료(DoD):
