# run — 컨텍스트 메뉴에 "압축 풀기"를 넣는다(압축 파일에서만 켜짐)

워크플로우 없이 직접 실행했다. 테스트 3개를 먼저 써서 빨간 상태를 확인한 뒤 구현했다.

## 슬라이스 결과
- S1 `ActionContext`에 `cursorIsArchive`를 더했다 — ⚠ `core.extract`의 `isApplicable`을 좁히는 부분은 하지 않았다(아래)
- S2 `CONTEXT_MENU`에 "압축 풀기" 항목 추가(여기에 압축… 바로 아래) — ✅

## 계획과 달라진 점
- 계획은 `core.extract`의 적용 조건을 압축 파일로 좁히는 것이었으나, 그러면 일반 파일에서 Actions Panel로 추출을 실행했을 때 나오던 안내("압축 파일(아카이브)을 선택하세요")가 사라진다(기존 테스트가 이 동작을 보장한다). 그래서 `core.extract`는 그대로 두고, 컨텍스트 메뉴 항목에만 `archiveOnly` 조건을 걸었다(압축 파일 위이거나 선택 항목이 있을 때 켜짐).
- 키보드로 메뉴를 열어 비활성 항목에서 Enter를 눌러도 기존 항목들처럼 액션이 실행되고, 일반 파일이면 같은 안내가 나온다.
- 기존 테스트 `우클릭하면 메뉴가 열리고 항목이 순서대로 나온다`의 기대 목록에 "압축 풀기"를 추가했다(명세 변경). 구분선 수는 그대로다.
- `actionContext`의 `cursorIsArchive`는 이름으로 판단한다(설정의 추가 확장자 포함).
