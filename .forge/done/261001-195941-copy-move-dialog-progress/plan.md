# 복사/이동 확인 창과 진행 창

## 목표 / 비목표
- 목표: F5/F6을 누르면 **전송 확인 창**이 먼저 뜨고(대상 폴더 편집 가능), 시작하면 **전송 진행 창**이 파일 단위 진행(N/M개)과 현재 복사 중인 파일 경로를 보여 준다. 복사와 이동 모두 해당한다.
- 비목표:
  - 대기열에 추가 버튼과 옵션 버튼 (사용자가 이번에는 구현하지 않기로 함).
  - 바이트 단위 진행. `fs::copy`를 청크 복사 루프로 바꾸지 않는다. 파일 하나가 큰 경우 그 파일이 끝날 때까지 막대가 멈춰 보이는 것을 감수한다.
  - 복사하면서 파일 이름 바꾸기. 입력창은 대상 폴더만 다룬다.
  - 확인 창을 끄는 설정(`core.confirm.copy` 등). 항상 뜬다.
  - 중단 시 이미 복사된 파일의 롤백. 현재 `A/D` 중단과 같이 그대로 둔다.
  - 기존 오른쪽 위 큐 배지와 `=` 큐 팝업 변경. 그대로 둔다.
  - 확인 창 입력창의 Tab 경로 완성.

## 합의한 동작
- 순서: F5/F6 → 전송 확인 창 → (이름이 겹치면 기존 충돌 창이 항목마다) → 큐에 넣기 → 300ms를 넘겨 아직 실행 중이면 전송 진행 창 표시.
- 전송 확인 창: 메시지("선택한 N개 항목을 복사/이동하시겠습니까?", 1개면 이름 표시), 대상 폴더 입력창(기본값 = 비활성 패널의 현재 경로), 취소/시작. Return=시작, Esc=취소.
- 대상 폴더 검증: 없는 폴더, 폴더가 아닌 경로, 원본 안쪽 경로는 창을 닫지 않고 창 안에 오류를 표시한다. 가상 탭(아카이브 등)이 비활성 패널이면 지금처럼 오류로 막는다.
- 전송 진행 창: 제목 "복사 중"/"이동 중", 막대 + `N/M개`, 현재 파일 경로, 중단 버튼(Esc도 중단). 끝나면 자동으로 닫힌다. 실패한 항목이 있으면 닫지 않고 오류 목록과 닫기 버튼을 보여 준다. 중단하면 닫힌다.
- 파일 개수는 작업 시작 시 폴더를 재귀로 훑어 구한다. 집계가 끝나기 전에는 "집계 중…"으로 표시한다.
- 이동이 같은 볼륨의 이름 바꾸기로 끝나면 사실상 즉시 끝나므로 진행 창이 뜨지 않는다.
