## 판단·발견
- ⚠ 계획과 다름 — 다중 열 보기 테스트는 계획의 DoD에 없었는데, 코드를 고친 경로(`multi`의 열 정의)가 비어 있어서 추가했다.
- 폴더 장식은 이름 열 텍스트에만 붙인다. 선택·정렬 등 다른 곳의 `e.name`은 그대로라서 이름 바꾸기 입력창은 장식 없는 이름으로 열린다(테스트로 고정).
- 줄무늬는 커서 행에서는 쓰지 않는다(커서 배경이 우선). 줄무늬 색은 새 변수 없이 `bg-app-line/20`(기존 테마 변수의 옅은 농도)이다. 이 농도가 라이트·다크 모든 테마에서 눈에 잘 보이는지는 **눈으로 확인하지 못했다.**
- 커서 행 꽉 채움은 `bg-accent text-white`다. 테마별 accent 색이 매우 밝으면 흰 글씨 대비가 낮을 수 있다. 실제 화면에서 확인하지 못했다.
- 설정 화면의 "폴더 모양" 드롭다운은 영문 값(`none`/`brackets`/`parens`/`slash`)이 그대로 보이고, 설명 문구에서 모양을 보여 준다. 기존 `테마`·`크기 형식`과 같은 방식이다.
- 한글 파일 이름은 테스트 데이터에서 NFD로 저장돼 있어 테스트의 기대값도 NFD로 맞췄다(기존 `NFD` 헬퍼).
