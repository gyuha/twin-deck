## 그때그때 내린 결정
- 줄 단위는 (액션, 인수, 스코프). 같은 액션이 여러 스코프에 있으면 줄 이름에 스코프를 붙인다.
- ×로 빼기: 사용자가 더한 키 → 항목 삭제, 기본 키 → `"none"`. `"none"`은 모든 스코프에 걸려서 다른 줄도 쓰는 기본 키(예: Enter)는 **막고 안내만** 한다 — 계획에 없던 한계.
- 앱 실행 액션은 편집기 줄에서 뺐다(F키 줄에서 앱 경로와 함께 고른다).
- 수식키 없는 글자 키는 녹화에서 거절한다(빠른 선택과 충돌).
- 녹화 칸은 `data-key-record`로 전역 키 처리(`useKeyboard`)에서 빠진다.
- 키 녹화가 잡는 범위: 웹뷰에 들어오는 키만. 앱 메뉴는 Cmd+Q 말고 네이티브 단축키를 달지 않으므로(`appMenu.ts:130`) Cmd 조합도 웹뷰로 들어온다고 본다(추론). 실제 WKWebView 녹화는 확인하지 못했다.
