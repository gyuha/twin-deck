# 단축키 설정 메뉴 UI

## 목표
설정에 "단축키" 메뉴를 만들어 모든 액션의 키를 녹화로 바꿀 수 있게 하고, F키·전역 단축키·폴더 단축키를 이 메뉴로 옮긴다. 다른 프로그램과 겹치는 키를 사용자가 피할 수 있게 하는 것이 목적이다.

## 진실의 원천
- 행 단위: (액션, 인수) 조합. 예: `core.go.shortcut` n=3이 한 행이고 옆에 폴더 경로(`shortcuts.3`)를 편집한다.
- 행마다 키 칩 여러 개, [×] 해제, [+] 녹화(Esc 취소), 행별·전체 "기본값으로".
- 같은 스코프 중복 입력 → "○○에서 쓰는 키입니다. 옮길까요?" 확인 후 원래 액션에서 해제.
- 다른 프로그램이 가로챈 키는 감지 불가 — 녹화 중 키가 안 들어오면 안내 문구만.
- F키 그룹: 동작(keybindings), 하단 바 표시(`fkey_bar`), 앱 경로(`fkey_apps`), 조합키 추가 유지.
- 전역 단축키: 화면만 이동, 저장은 `config.toml`의 `environment.global_hotkey` 그대로.

## 슬라이스
- [ ] S1. 단축키 메뉴 골격: 검색 + 액션 행 목록 + 현재 키 칩(기본+사용자 병합 결과) — 완료 기준: vitest로 목록·검색 표시.
- [ ] S2. 녹화·해제·기본값으로·스코프 중복 확인 — 완료 기준: FakeBackend로 저장 결과와 중복 이동을 검증하는 vitest 통과.
- [ ] S3. F키 그룹·전역 단축키·폴더 단축키 이동, 옛 `F키`·`폴더 단축키` 섹션과 환경의 전역 단축키 항목 제거 — 완료 기준: 설정 탭 목록 테스트·`fkey-bindings.test.tsx` 갱신 후 통과.
- [ ] S4. 문서: `docs/05-actions-keybindings.md`에 단축키 메뉴 설명, i18n ko/en — 완료 기준: 문서에 메뉴 사용법 절 존재.

## 완료 정의
- `cd apps/desktop && bunx tsc --noEmit && bunx vitest run` 통과 (사전 상태: 통과, 회귀 가드).
- UAT: 격리 인스턴스에서 F5를 다른 키로 바꾸고 실제 복사 동작 확인, `Ctrl+3` 재지정 후 폴더 이동 확인, 하단 바 F키 표시 유지 확인.

## 하지 않을 것
- OS 수준 단축키 충돌 자동 감지.
- 액션당 키 1개 제한.
