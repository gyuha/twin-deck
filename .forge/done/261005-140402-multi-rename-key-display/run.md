# run — 다중 이름 바꾸기 단축키(Mod+Shift+R)를 Help와 File 메뉴에 정확히 표시한다

워크플로우 없이 직접 실행했다.

## 슬라이스 결과
- S1 Help 표기 확인, File 메뉴 항목 글자에 키 표시 — ✅ Help는 이미 정확했고(코드 변경 없음), File 메뉴 항목에 `keyOf`로 키를 붙였다

## 계획과 달라진 점
- 사용자 결정에 따라 키는 바꾸지 않았다. 이슈 #7의 `Mod+Shift+F`는 이미 빠른 선택 시작 키이고, 다중 이름 바꾸기는 이미 `Mod+Shift+R`이다(이전 커밋 f23604c). 이슈의 "Mod+F로 되어 있다"는 서술은 현재 코드와 다르다(스크린샷은 볼 수 없었다).
- DoD 1의 Help 표시·키 동작·충돌 테스트는 구현 전에도 통과했다(이미 맞는 동작을 고정하는 회귀 방지). 전진 검사는 File 메뉴 글자 테스트 하나였다.
- `keyOf`는 File 메뉴 모든 항목에 적용된다. 키가 있는 항목은 모두 `복사 (F5)`처럼 글자 뒤에 키가 붙는다. 다중 이름 바꾸기만 따로 처리하면 메뉴가 일관되지 않아서다. 필요하면 다중 이름 바꾸기만 남기도록 좁힐 수 있다.
