# 파일 찾기 다이얼로그(기본 탭)와 Cmd/Ctrl+F

## 목표 / 비목표
- 목표: 첨부 이미지의 Double Commander "파일 찾기" 다이얼로그 **기본 탭**을 만든다. `Mod+F`(mac Cmd+F, 그 외 Ctrl+F)로 열고 Esc로 닫는다.
  - **키**: 새 액션 `core.find.open`(스코프 `pane`, 기본 키 `Mod+F`)과 모달 스코프 `find`(`Scope` 유니온과 모달 스코프 목록에 추가; Esc로 닫는 `core.find.close`). **Quick Select는 `Mod+Shift+F`로 옮긴다**(`core.quickselect.start` 기본 키 변경). `docs/05-actions-keybindings.md`의 해당 행을 갱신하고 `core.find.open` 행을 추가한다.
  - **다이얼로그**(제목 "파일 찾기", `role="dialog"`, 이름 `파일 찾기`): 위쪽에 탭 띠(기본 · 고급 · 플러그인 · 불러오기/저장 · 결과). **기본만 활성**이고 나머지는 비활성(`aria-disabled`)으로 보인다. 세 영역:
    - **디렉터리**: `디렉터리에서 시작(D)` 입력(기본값 = 활성 패널의 현재 폴더, 가상 탭이면 그 탭의 기준 폴더), 체크 `열려있는 탭` · `선택한 디렉터리 및 파일`(활성 패널에 선택이 없으면 비활성) · `심볼릭 링크 따라가기`, `하위 디렉터리 제외(X)` 입력, `하위 디렉터리에서 검색(B)` 선택(`모두 (무제한 깊이)` · `현재 디렉터리만` · `1단계` … `9단계`).
    - **파일**: `파일 마스크(F)` 입력, 체크 `압축파일에서 찾기`(비활성) · `파일 이름의 일부로 검색`(기본 켜짐) · `정규식`, `파일 제외(E)` 입력.
    - **데이터 찾기**: 체크 `파일에서 텍스트 찾기`(켜면 아래 입력과 옵션이 활성), 텍스트 입력, `바꾸기`(비활성) 와 그 입력(비활성), `텍스트를 포함하지 않는 파일 찾기` · `대소문자 구분` · `정규식`(텍스트 찾기를 켰을 때 활성), `Office XML`(비활성), `인코딩(G)` 선택(비활성, Default), `16진수`(비활성). 비활성 항목에는 `title="아직 지원하지 않습니다"`.
    - 오른쪽 버튼: `시작`(주 버튼), `취소`, `닫기`, `새 검색`, `마지막 검색`.
  - **동작**: `시작`을 누르면 `FindSpec`을 만들어 `backend.startFind`로 보내고, 다이얼로그를 닫고, 결과를 Look Up과 같은 **새 가상 탭**에 스트리밍한다(`openVirtual`; 제목 `Find: <마스크 또는 찾는 텍스트>`; 기존 VirtualHeader의 진행·취소 표시 재사용, 필요하면 `VirtualKind`에 `"find"` 추가). 열려있는 탭이 체크되면 양쪽 패널의 모든 탭 중 가상 탭이 아닌 것의 폴더를 `roots`로, 선택 항목 체크면 활성 패널의 선택 경로를 `only_items`로 보낸다. 입력 오류(잘못된 정규식 등)는 다이얼로그를 닫지 않고 다이얼로그 안에 `role="alert"`로 보여 준다. `새 검색`은 입력과 옵션을 기본값으로 되돌린다. `마지막 검색`은 직전에 시작한 조건을 되살린다(메모리에만 보관, 앱을 다시 켜면 사라짐; 없으면 비활성). `취소`는 검색이 진행 중일 때만 활성이고(진행 중에 다이얼로그를 다시 열 수 있다) 누르면 그 검색을 멈춘다(`core.search.cancel`과 같은 경로).
- 비목표: 고급/플러그인/불러오기·저장/결과 탭의 내용, 바꾸기·Office XML·인코딩·16진수·압축파일 안 검색의 실제 동작, 폴더 찾아보기(파일 선택 창) 버튼, 결과를 다이얼로그 안에 보여 주는 것, 검색 조건의 영구 저장.
