## 현장 결정과 차이
- 새 불리언 키 대신 기존 view.table.columns를 조작해 설정 충돌을 피했다. Rust 타입·명령 변경이 없어 타입 재생성은 불필요하다.
- 전체 검사의 기존 테스트 환경 문제를 범위 내 수정했다: actions의 cursorIsArchive·usageTab 기본값, WASM 모듈 경로 해석, PDF Blob의 FileReader 검증, Node Request와 호환되는 취소 신호.
- 제품의 PDF/3D 모델 동작은 수정하지 않았다. 수동 WKWebView 검증은 수행하지 않았고 승인된 UI 자동 테스트로 검증한다.
- 자동 수정 3/3회. 실제 기능 구현의 설계 변경은 없다.
