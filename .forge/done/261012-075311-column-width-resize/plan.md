# 목록 헤더에서 컬럼 너비를 끌어 조절한다

## 목표 / 하지 않을 것
- 목표: 파일 목록 **헤더**의 컬럼 경계를 끌어 컬럼 너비를 조절한다. 파일 행에는 손잡이가 없다. 조절한 너비는 설정 파일의 컬럼 명세(`view.table.columns`, 예: `["name", "size:110", "modified"]`)에 저장되어 모든 탭·패널이 같이 쓰고 재시작해도 남는다. (GitHub 이슈 #48)
  - 사용자 결정: 저장은 **전체 공통, 설정 파일**. (문서 `docs/07` §4.2의 "탭 단위로 저장"은 이 결정으로 고친다.)
  - 동작 모델: 각 컬럼의 **왼쪽 경계**가 손잡이다. 그 경계를 왼쪽으로 끌면 그 컬럼이 넓어지고 오른쪽으로 끌면 좁아진다(이름 컬럼이 남는 폭을 차지하므로 전체 폭은 그대로다). 이름 컬럼은 손잡이가 없다. 최소 40px, 최대 600px. 끄는 동안 헤더와 모든 행이 같은 너비로 바로 바뀌고(미리보기), 마우스를 놓을 때 한 번 저장한다.
  - 저장 형식: 현재 설정의 컬럼 명세 문자열을 그대로 두고 그 컬럼의 `:너비`만 바꾼다(정렬 표시 `<`·`>`와 순서 유지). 설정 쓰기(`set_user_value`)가 문자열 목록을 쓰도록 `ConfigValue::StrList`를 더한다(Rust + 생성 바인딩).
- 하지 않을 것: 탭별 너비 · 이름 컬럼 너비 조절 · 컬럼 순서 바꾸기·추가·삭제 · 여러 컬럼 보기(헤더가 없다) · 너비 되돌리기 UI(설정 파일에서 컬럼 명세를 고치거나 `reset`) · 파일 행에서의 조절
