## 판단·발견
- 상위 폴더 키는 사용자 메모와 달리 `←`(오른쪽이 아니다)다. 결과는 같아서 그대로 진행했고 계획에도 그렇게 적었다.
- ⚠ 확인하지 못한 것: 실제 앱에서 `..` 줄이 사라진 모양과, 줄이 빠져 목록이 한 줄(약 24px) 위로 올라온 것이 어색하지 않은지는 눈으로 보지 못했다. 이슈 #22 코멘트의 파란 테두리(그 버튼의 포커스 링)도 버튼이 없어졌으니 사라졌을 것이나 직접 확인하지 못했다.
- 마우스만 쓰는 사용자는 "더블클릭으로 올라가기"를 잃는다. 경로 표시줄의 상위 조각 클릭으로 대신한다. 이 변경은 다음 릴리스의 변경 사항(`CHANGELOG.md`)에 "`..` 줄 제거"로 적어야 한다.
