# 실행 기록 — SMB 연결 UI (#168, 2/2)

워크플로 `wf_acd02934-bc3`(에이전트 3개, 순차: 설정 탭 → DriveBar 연결·비밀번호 창 → 문서·적대적 검토·DoD). 약 17분.

## 작업 단위별 결과
- S1 설정 SMB 탭(목록+폼, 비밀번호 지우기) — ✅ 계획대로 (⚠ 삭제·수정은 초안에만 반영되고 "저장"에서 한 번에 기록, 지우기는 미저장 변경이 있으면 비활성)
- S2 DriveBar "연결" 메뉴 — ⚠ 팝업 메뉴에 마우스 클릭 선택·배경 클릭 닫기를 추가함(계획 밖, Volumes·Favorites·Recent·Parent 메뉴에도 적용됨)
- S3 연결 흐름·비밀번호 대화상자 — ✅ 계획대로 (+ 검토 단계가 보안 결함을 고침: 연결 대기 중 서버 목록이 바뀌면 다른 서버로 비밀번호가 전송될 수 있었음 → host/share/user 비교로 중단, 회귀 테스트 추가)
- S4 i18n·README 쌍 — ✅ 계획대로
- S5 실제 NAS로 UI 확인 — ⏳ 사람 확인 대기

## DoD 기준값 → 실행 후
1. drive-bar 테스트: 기존 통과 → 30 통과(새 케이스 포함)
2. settings 테스트: 기존 통과 → 31 통과
3. tsc + `bun run test`: 통과(회귀 방지) → 통과(desktop 1390 등)
4. i18n-keys + `grep -c -i smb ko.ts`: 키 테스트 통과(회귀 방지)·0 → 7 통과·24
5. 실제 macOS 마운트·WKWebView 확인: 미실행 → 대기 (1/2 DoD 7도 여기서 함께 확인)

## 남은 우려
- `smbConnecting`이 인덱스 기준이라 연결 중 목록이 바뀌면 "연결 중…" 표시가 다른 항목에 잠깐 붙을 수 있음(표시만, 연결은 보호됨).
- SMB 탭에 저장 안 한 편집이 있을 때 설정이 밖에서 바뀌면 초안이 새 목록으로 교체됨.
