# twin-deck

## 네트워크 공유

**SMB 서버 항목**:
사용자가 저장해 둔 SMB 공유 하나. 표시 이름, 호스트, 공유 이름, 사용자 이름으로 이루어진다. 같은 서버의 공유가 둘이면 항목도 둘이다. 비밀번호는 항목에 속하지 않고 기기의 키체인에 따로 있다.
_Avoid_: 연결, 즐겨찾기 (즐겨찾기는 로컬 경로 목록이다)

**SMB 연결**:
SMB 서버 항목을 OS에 마운트해 볼륨으로 만드는 일. 연결이 끝나면 그 공유는 다른 볼륨과 똑같이 다뤄지고, 연결 해제는 볼륨 언마운트와 같다.
_Avoid_: 접속, 로그인
