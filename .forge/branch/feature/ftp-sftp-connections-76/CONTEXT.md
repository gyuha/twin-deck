# twin-deck

## 네트워크 공유

**원격 서버 항목**:
사용자가 저장해 둔 SFTP 또는 FTP 서버 하나. 표시 이름, 프로토콜(`sftp`|`ftp`), 호스트, 포트, 사용자 이름, 시작 폴더로 이루어진다. 비밀번호는 항목에 속하지 않고 기기의 키체인에 따로 있다. SMB 서버 항목과 달리 OS에 마운트하지 않는다.
_Avoid_: 연결, 즐겨찾기 (즐겨찾기는 로컬 경로 목록이다)

**원격 연결**:
원격 서버 항목으로 세션을 열어 패널이 그 서버의 폴더를 로컬 폴더처럼 보게 하는 일. 앱의 원격 `Vfs`가 세션을 들고 있고, 복사·이동·삭제·이름 바꾸기는 기존 작업 경로(`Ops`)를 그대로 쓴다. 연결을 끊으면 세션이 닫힌다.
_Avoid_: 마운트 (OS 마운트는 SMB 연결 쪽 말이다), 접속, 로그인
