# 설정 화면 "F키" 섹션

## 목표 / 비목표
- 목표: 설정 화면에 "F키" 섹션을 추가한다. F1~F12 각각에 선택 메뉴(기본값 · 해제 · 액션 목록 · **애플리케이션 실행**)가 있다.
  - 선택 메뉴의 값은 `config.fkeys.Fn`에 저장한다(`기본값` = `""`, 해제 = `"none"`). Radix Select는 빈 문자열 값을 허용하지 않으므로 UI에서만 `"default"` 같은 값으로 바꿔 쓰고 저장 때 `""`로 되돌린다.
  - 선택 메뉴에는 "기본값 (현재: <기본 액션 이름 또는 없음>)" 항목이 있어 비워 둔 키가 무엇을 하는지 보인다.
  - **애플리케이션 실행**을 고르면 같은 행에 앱 경로 입력 상자(`config.fkey_apps.Fn`)가 나타난다. 입력은 기존 텍스트 입력처럼 넓게, Enter/포커스 해제로 저장한다.
  - 액션 목록은 레지스트리에서 가져오되 `pane` 스코프로 쓸 수 있는 액션만 보인다(다이얼로그·메뉴 전용 액션 제외). 도움말(`core.help`)과 앱 실행(`core.app.launch`)이 포함된다.
  - 섹션 설명(제목 아래)에 "키를 비우면 기본값, keybindings.toml 설정이 이 설정보다 우선한다"는 안내를 넣는다.
- 비목표: 앱 경로 찾아보기(파일 선택 창), 키 충돌 감지, F키 외 키(Ctrl+숫자 등)의 설정 UI.
