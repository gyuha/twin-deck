# twin-deck (브랜치 explore-remote-support-design 추가 용어)

## 원격 접속

**원격 호스트**:
다른 PC에서 데몬 모드로 실행 중인 Twin Deck. 사용자 설정에 별칭과 주소, 토큰으로 등록한다.
_Avoid_: 서버, 리모트 PC (데몬을 띄우지 않은 PC는 원격 호스트가 아니다)

**원격 데몬**:
창 없이 실행된 Twin Deck으로, 파일 작업을 네트워크로 받아 처리한다.
_Avoid_: 에이전트, 백엔드 (Backend는 UI가 쓰는 인터페이스 이름이다)

**원격 경로**:
`td://별칭/원격경로` 형식으로 원격 호스트 안의 위치를 가리키는 경로. 원격 안의 아카이브도 `!/`로 이어 쓴다.
_Avoid_: URL, 원격 주소 (주소는 원격 호스트의 네트워크 주소를 뜻한다)
