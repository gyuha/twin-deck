# 나이트 쿠리어 · 운송 경로 개선 스펙

## 목적과 시그니처
키보드로 파일을 정리하는 사용자를 위한 기존 6개 영역을 유지한다. 분위기는 야간·정밀·따뜻함. 시그니처는 캐릭터가 전달하는 파일 궤적을 아래의 번호 매긴 경유지로 이어가는 운송 경로다. 새 심벌이나 가상 제품 UI는 추가하지 않는다.

## 파일·서체·색상
기존 index.html, styles.css, main.js 구조. 외부 의존성 없음. 시스템 한국어 산세리프와 키캡의 시스템 모노를 유지한다. 배경 #101012, 본문 #f5f1ec, 보조 #b0aaa5, 선 #38312f, 강조 #ff794b. 첫 CSS 규칙에서 html/body 배경을 고정한다. 브랜드의 빨간 원본 아이콘을 보존한다.

## 자산과 레이어
assets/night-city.webp와 작은 srcset은 cover, 중앙 초점으로 도시를 배치한다. courier.webp는 투명 독립 레이어로 유지한다. main.png, preview-code.png, find.png, treemap.png, theme-dracula.png는 원본 비율을 지킨다. 영어는 assets/en/의 동일 파일. 기존 lazy loading 유지. 도시 0 → 캐릭터 1 → 제품·본문 2 → 내비게이션 10. 장식은 pointer-events:none. 새로운 네트워크 자산 없음.

## 첫 화면
문구 “두 개의 패널. 하나의 흐름.”과 기존 설명·다운로드·키 링크 유지. 1280px 컨테이너와 48px 여백. 데스크톱 장면 높이 860px, 캐릭터 폭 610px, 왼쪽 -35px, 위 -12px. 제목은 기존 58–83px/800/1.13, 우측 46% 영역, 위 여백 32px. 제품은 위 520px, 폭 74%, 회전 -2deg 유지. 스크린샷과 궤적이 CTA 영역 아래에 오도록 간격 확보. 768–1279px는 기존 태블릿 배치 유지. 1280px 이상·높이 760px 이하는 장면 770px, 캐릭터 520px, 제품 위 460px/폭 66%, 제목 64px로 조정한다.

## 섹션
경유지 01/02/03/04는 CSS counter로 기존 section-heading 및 personal-heading에 추가한다. 모노 12px/600, tracking .14em, 주황, 40px 가로선, 제목 위 24px. 읽기 내용이나 앵커는 바뀌지 않는다. 기본 섹션 간격 112px 유지.

workflow: 키 체험판 상단에 2px 주황선을 두고 키캡 중심 정렬 유지. 내부 스크린샷과 설명의 의미는 변경하지 않는다.
features: 탭은 44px 이상 높이와 주황 밑줄로 선택 상태를 표시한다. 갤러리는 불필요한 둥근 외곽을 줄이고 상하 경계로 제품을 진열한다. 화면 좌우 28px 여백.
more: 12열 비대칭 구성 유지, 간격 1px로 통합 작업 보드처럼 연결. 카드 배경을 #171719로 통일, 반경 0, 바깥 경계 #38312f, 바깥 반경 12px. 각 카드 안쪽 40px 유지.
personal: 숫자는 112 최종값/1회/2초 cubic 감속 유지. 숫자 굵기를 500으로 낮춰 제목과 대비. 화면 위쪽 1px 경계 유지.
download: 도시 재등장과 기존 다운로드·설치 명령 복사 유지. 버튼 최소 44px, 명령 복사 터치 높이 44px.

## 모션
기존 7초 캐릭터·6초 폴더 경로를 유지한다. 첫 화면 본문을 제목 0ms → 설명 100ms → 버튼 180ms → 키 260ms로 분리해 650ms ease-out, y 18px → 0. 전체 910ms 안에 끝난다. 제품은 1.1초. 섹션 750ms. 화면 밖·비활성 탭 중단 유지. reduced-motion은 전부 정지, 내용은 최종 상태. JS가 없거나 실패해도 콘텐츠는 기본 표시된다. 스크롤 가로채기 없음.

## 모바일·대체 동작
767px 이하는 기존 문구 우선 순서. 캐릭터 430px/위 355px, 제품 위 660px, 장면 850px. 제품 폭 100%, 회전 제거, 스크린샷 원본 비율 유지. 500–767px는 장면 990px, 캐릭터 540px, 제품 위 730px. 374px 이하는 장면 860px, 캐릭터 위 390px, 제품 위 700px, 본문·CTA와 겹치지 않도록 한다. 영문은 긴 제목에 맞춰 자연스러운 줄바꿈을 허용한다. 320px에서 가로 넘침 없음. 시스템 라이트에서도 다크 유지.
