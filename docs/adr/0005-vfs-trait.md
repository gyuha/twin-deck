# ADR-0005. `Vfs` trait로 아카이브를 폴더처럼

- 상태: Accepted
- 날짜: 2026-09-29

## 맥락

Marta는 아카이브를 폴더처럼 탐색하고, 안의 파일을 복사/편집하며, 중첩 아카이브도 연다. Spacedrive 코어에는 zip/tar 처리 코드가 없다(`crates/archive`는 외부 데이터 인덱서).

## 결정

`td-vfs`에 `Vfs` trait를 두고 `LocalFs`와 `ArchiveFs`(ZIP 읽기/쓰기, tar/rar 등 읽기 전용)를 구현한다. 위치는 `VfsPath { fs, path }`로 표현하며, 아카이브 마운트는 부모 `VfsPath`를 기억하여 중첩을 표현한다. 구현체별 능력(쓰기 가능 여부, 감시 가능 여부)은 `capabilities()`로 조회한다.

## 결과

- 장점: UI와 파일 작업 코드가 로컬/아카이브를 구분하지 않는다. 새 파일시스템(예: 원격)을 추가할 때 trait 구현만 하면 된다.
- 단점: 아카이브 되쓰기는 아카이브 전체를 다시 쓰므로 큰 아카이브에서 비용이 크다. 읽기 전용 형식은 쓰기 연산을 거부해야 한다.
- 후속: 형식별 라이브러리 선정(rar 등), 되쓰기 실패 시 원본 보존 검증.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 아카이브를 임시 폴더로 통째 추출 | 큰 아카이브에서 느리고 되쓰기/정리가 복잡. Marta의 폴더처럼 열기와 다름 |
| 아카이브 기능 제외 | 요청한 Marta 기능 패리티에 반함 |
