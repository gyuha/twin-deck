# ADR-0006. 설정 형식은 TOML

- 상태: Accepted
- 날짜: 2026-09-29

## 맥락

Marta는 `conf.marco`(Marco DSL: 따옴표 없는 키, `:`/`,` 없음, `${var}` 보간, 배열은 `[a b]`)를 쓰고 내장 편집기에서 읽기 전용 기본값 위에 사용자 값을 덮어쓴다. Marco의 파서는 Marta 저장소가 공개한 별도 라이브러리(MarcoKit)에 있다. Marta와의 설정 호환은 요구사항이 아니다.

## 결정

설정과 키바인딩, 테마는 TOML로 한다. 내장 기본값 위에 사용자 파일을 깊은 병합하는 방식은 Marta와 같게 한다. `${...}` 변수 보간은 경로와 Gadget 인수에서만 twin-deck이 직접 처리한다.

## 결과

- 장점: Rust `toml`/`serde`로 바로 파싱하고 스키마 검증이 쉽다. Spacedrive도 TOML을 쓴다.
- 단점: Marco의 간결한 문법(`null` 값, 구분자 없는 배열)을 쓸 수 없어 해제/구분선 표현이 달라진다(`"none"`, `type = "separator"`). Marta 설정을 그대로 가져올 수 없다.
- 후속: 스키마 문서화([06](../06-config-plugins.md)), 설정 검증기 구현.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| Marco 호환 파서 작성 | 호환이 요구되지 않으며 Rust 생태계에 기성 파서가 없음 |
| JSON/JSON5 | 주석과 사람이 편집하는 가독성에서 TOML이 유리 |
| YAML | 들여쓰기 오류와 암묵적 타입 변환 위험 |
