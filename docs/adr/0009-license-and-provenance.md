# ADR-0009. 라이선스와 출처 추적

- 상태: Accepted
- 날짜: 2026-09-29

## 맥락

Spacedrive 루트 라이선스는 FSL-1.1-ALv2이며 Competing Use를 금지한다. 파일 관리자는 Spacedrive와 실질적으로 유사한 기능을 제공할 수 있어 경쟁 사용에 해당할 가능성이 있다(법률 해석은 확정이 아니다). 내부 사용은 허용된다. 저장소 안에서도 표기가 엇갈린다: `packages/interface`, `packages/assets`는 `GPL-3.0-only`, `packages/ts-client`는 `GPL-3.0`, `crates/sdk`는 `MIT OR Apache-2.0`, 대부분의 Rust 크레이트는 워크스페이스 상속(FSL). NOTICE 파일은 없다.

사용자는 twin-deck의 사용 범위를 **개인/사내 전용**으로 확정했다.

## 결정

- 개인/사내 전용 범위에서는 Spacedrive 소스를 직접 복사해 사용한다.
- 이식한 모든 파일에 출처 헤더를 붙이고 루트 `THIRD_PARTY_NOTICES.md`에 원본 경로, 커밋, 선언된 라이선스, 전략, 날짜를 기록한다. FSL 전문을 `licenses/`에 포함한다.
- Rust 이식 크레이트는 `license`를 상속하지 않고 `FSL-1.1-ALv2`로 명시한다.
- GPL 표기 패키지에서 온 TS 코드는 `gpl-tainted`로 표시해 교체 대상을 즉시 식별한다.
- Marta의 코드, 아이콘, 테마, 문서 문장은 복사하지 않는다.

**재검토 조건.** 다음 중 하나가 발생하면 이 ADR을 다시 열고 이식 코드의 유지/재작성을 결정한다.

1. twin-deck을 사내 밖으로 배포하거나 공개한다.
2. 판매, 구독, 광고 등 상업적 이용을 시작한다.
3. 사내 다른 법인(계열사 등)이나 외부 협력사에 제공한다.
4. Spacedrive 라이선스 조건이 바뀌거나 GPL 표기의 실제 적용이 확인된다.

## 결과

- 장점: 요청한 "재사용 소스를 그대로 사용"을 지키면서 위험 파일을 추적할 수 있다.
- 단점: 파일마다 헤더/기록을 관리해야 한다. 재검토 조건이 발생하면 재작성 비용이 든다.
- 후속: 헤더 규칙 적용(M0), 배포 전 점검(M5). 사내 배포가 GPL 표기 코드의 "배포"에 해당하는지는 법률 자문 대상이며 이 문서에서 판단하지 않는다.

## 검토한 대안

| 대안 | 기각 이유 |
|---|---|
| 코드 복사 없이 아키텍처만 참고 (클린룸) | 개인/사내 전용이라 불필요한 재작성 비용. 배포 범위가 확대되면 재검토 |
| 출처 기록 없이 복사 | 재검토 시 교체 대상을 알 수 없음 |
