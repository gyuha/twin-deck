# emojibase 데이터

이모지 선택기(`frimousse`, `apps/desktop/src/ui/Settings.tsx`의 `IconField`)가 인터넷 없이 쓰는 이모지 데이터다.
[`emojibase-data`](https://www.npmjs.com/package/emojibase-data) 16.0.3(MIT)의 `ko`·`en`에서 `data.json`과 `messages.json`만 그대로 복사했다.
`frimousse` 0.4.0이 `emojibase-data` 16.x 기준으로 만들어져 같은 메이저를 썼다. 언어를 더하거나 올릴 때는 같은 두 파일을 `<언어>/`에 넣는다.
